Security status
• Chat messages are relayed through the server in readable form in this prototype; don't send sensitive information.
• WebRTC media uses browser-managed encrypted transport, but this app has not had an independent security audit and does not implement app-layer E2EE verification.
• For some networks, calls may need a TURN relay service.
